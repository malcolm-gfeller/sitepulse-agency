# SitePulse Agency

Modern website for a Swiss digital growth agency.

## Features
- ✨ Modern UI with Tailwind CSS
- 🚀 Dynamic animations with Framer Motion
- 🤖 Integrated Gemini AI Chat Assistant
- 📱 Fully Responsive Design

## Run Locally

1. Install dependencies:
   `npm install`
2. Set the `VITE_GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   `npm run dev`
